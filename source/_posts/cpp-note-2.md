### 一、引用是什么(基本概念)

- 引用不是新定义一个变量，而是给已存在变量取了一个别名，编译器不会为引用变量开辟内存空间，它和它引用的变量共用同一块内存空间。比如：水浒传中李逵叫"铁牛"，江湖上人称"黑旋风"。

- 那我们为什么要使用引用呢？这主要是为了解决一些在c语言中不方便实现的情况

- 引用的语法： 类型& 引用别名 = 引用对象;

- 例如

  ```
  int& b = a;
  int& c = a;
  //b和c都是a的引用,所以b和c的地址和a是一样的，b和c都是a的别名
  ```

  当然，我们也可以给别名取别名，例如

  ```c++
  int& d = b;
  //d相当于还是a的别名
  ```

  下面展示完整的代码

  ```c++
  int main()
  {
  	int a = 0;
  	int& b = a;
  	int& c = a;
  	int& d = b;
  	++d;

  	cout << &a << endl;
  	cout << &b << endl;
  	cout << &c << endl;
  	cout << &d << endl;

  	return 0;
  }
  ```

  输出结果:(可以看出输出的4个地址都相同，b,c,d的本质都是表示a)

  ```c++
  0000005EC20FFD04
  0000005EC20FFD04
  0000005EC20FFD04
  0000005EC20FFD04
  ```


- 注意：引用对已有变量的别名,引用必须初始化,不能为NULL,引用一旦初始化后就不能改变引用的对象，不会开辟一块新的空间，而是和原来的变量共享同一块内存空间



##   二，引用的使用

  引用在实践中主要是于引用传参和传引用返回中减少拷贝提高效率和改变引用对象时同时改变被引用对象。

  • 引用传参跟指针传参功能是类似的，引用传参相对更方便一些。

  • 传值返回会产生临时对象作为函数调用表达式的返回值，传引用返回本质是返回返回对象的引用(别

   名)，从而提高了效率，同时可以改变返回对象。

  • 引用和指针在实践中相辅相成，功能有重叠性，但是各有特点，互相不可替代。



- 下面我们来看引用相比于指针的优势之处，当我们用c语言实现函数时需要传实参的地址，因为因为形参的改变不影响实参，这就导致不太方便。所以在c++中引入了引用来解决，引用是对实参的别名，改变的就是实参

  本身，下面我们来看一组简单的代码

  ```c++
  void swap(int* x, int* y)
  {
  	int temp = *x;
  	*x = *y;
  	*y = temp;
  }

  int main()
  {
  	int a = 10, b = 20;
  	swap(&a, &b);
  	printf("%d\n", a);
  	printf("%d\n", b);
  	return 0;
  }

  ```

```c++

void swap(int&rx ,int &ry)
{
	int temp = rx; //rx和ry的改变就是实参的改变
	rx = ry;
	ry = temp;
}

int main()
{
	int  x = 0, y = 1;
	cout << x << " " << y << endl;

	swap(x, y);  //直接传实参
	cout << x << " " << y << endl;

	return 0;
}
```



输出结果 ：（成功实现交换）

```c++
0 1
1 0
```

## 三、const 引用(权限放大 / 缩小)

- 核心规则:**权限不能放大,只能缩小**。

- 对照表:const 对象只能绑 const 引用;普通对象可以绑 const 引用(缩小);`int c = a` 是拷贝不算权限问题

- 补充坑:`const double& re = d;` 可以,但 `double& re = d;` 不行(int 无法初始化 double 引用)——隐式类型转换产生临时量。


  ### 权限不能放大

```c++

const int a = 1;
int& r = a;       //错误写法   用"可写"的引用去绑"只读"的 a,权限放大
const int& r = a; //正确写法   只读绑只读,权限不变


int* p1 = &a;          // 错误：权限放大
const int* p1 = &a;    // 正确：只读指针指只读对象，权限不变
```

-  编译报错：error C2440: “初始化”: 无法从“const int”转换为“int &
-  这里不加const的引用是对a访问权限的放大



### 权限可以缩小

```c++
int b = 2;
const int& rr = b; //const 引用/指针不改变原对象的属性,不影响b的可读可写属性
```





 没有权限放大和缩小，本质是a拷贝给c，c的改变不影响a，指针和引用才有权限放大和缩小

```c++
int c = a;
```





### 非 const 引用不能绑临时变量、const 引用可以

```c++
int d = 1;
double e = d;
double& re = d; //错误，无法用int类型的值初始化double类型的引用
const double& re = d;  //const 引用可以绑定临时对象,生成了一个临时 double变量,re 绑定的是那个临时变量,不是 d 本身。
```

我们可以验证一下

```c++
int d = 1;
const double& re = d;   // re 绑定临时 double,值是 1.0

d = 100;                 // 改 d
cout << re << endl;      // 输出 1.0,不是 100
```



## 四，指针和引用的关系

C++中指针和引用就像两个性格迥异的亲兄弟，指针是哥哥，引用是弟弟，在实践中他们相辅相成，功

能有重叠性，但是各有自己的特点，互相不可替代。

• 语法概念上引用是一个变量的取别名不开空间，指针是存储一个变量地址，要开空间。

• 引用在定义时必须初始化，指针建议初始化，但是语法上不是必须的。

• 引用在初始化时引用一个对象后，就不能再引用其他对象；而指针可以在不断地改变指向对象。

• 引用可以直接访问指向对象，指针需要解引用才是访问指向对象。

• sizeof中含义不同，引用结果为引用类型的大小，但指针始终是地址空间所占字节个数(32位平台下

占4个字节，64位下是8byte)

• 指针很容易出现空指针和野指针的问题，引用很少出现，引用使用起来相对更安全一些。

### 五、内联函数 inline

• 用inline修饰的函数叫做内联函数，编译时C++编译器会在调用的地方展开内联函数，这样调用内联

函数就不需要建立栈帧了，就可以提高效率。



• inline对于编译器而言只是一个建议，也就是说，你加了inline编译器也可以选择在调用的地方不展

开，不同编译器关于inline什么情况展开各不相同，因为C++标准没有规定这个。inline适用于频繁

调用的短小函数，对于递归函数，代码相对多一些的函数，加上inline也会被编译器忽略。



• C语言实现宏函数也会在预处理时替换展开，但是宏函数实现很复杂很容易出错的，且不方便调

试，C++设计了inline目的就是替代C的宏函数。
